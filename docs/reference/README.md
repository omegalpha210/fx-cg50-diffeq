# Local reference manuals

Development used official/reference calculator manuals, which are not redistributed
with this repository. Obtain documentation from CASIO where appropriate:
https://edu.casio.com/support/manuals/

Local copies of diff_eq_manual.pdf and fx-CG50_manual.pdf may be placed here;
PDFs and extracted manual page images are ignored. Do not submit them in pull requests.
The source, tests and normal builds do not require these PDFs.
