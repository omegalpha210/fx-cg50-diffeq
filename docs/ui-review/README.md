# Host UI review frames

These are 396×224 framebuffer dumps from the actual production UI sources linked
to the host drawing/key adapter. They are not calculator/emulator screenshots.

`host-overview.png` contains 65 current views. `trace-ic-overview.png` shows
nine new cases: upper/lower TRACE follow, FAST/FASTER selection, Graph Settings,
ten initial values, the last Table columns and distinct count/length errors.
This sheet was visually inspected for readability and softkey placement.
`polish-overview.png` includes the retained 14 contextual-help cases plus these
nine cases. Seven-row IC/OUTPUT help remains clear of the final state.

`ux-field-overview.png` also includes the retained editor/TRACE/field and
simplified OUTPUT/IC/Table views. Other individual PNGs include field appearance,
one complete 2nd/SYS9 vector, ON/OFF and six-color chooser, two-solution Table
center, TOP/BTM, frozen x with many solutions, malformed list and numerical-limit
Table. Existing Graph/G-Solve/TRACE/ZOOM views remain.

The host adapter uses the attributed gint font8x9 atlas documented in
`tests/host/vendor/README.md`. Production `dsize` measurements check the current hint/context
strings against 368 available pixels; EDIT is 243, OUTPUT 189, comma 128, and the
longest V-WIN context 336 pixels. The ten-IC hint is 247, Main MENU is 194 and overflow feedback is 266 pixels.
Logical hint y=184 becomes LCD y=188, above the softkey bar at y=202. Host
pixel tests also compare PREV's existing magenta style and all six pale swatches.

Regenerate with `python3 tools/capture_ui.py`. Every displayed
screen is produced by scripted physical key events through production handlers.
Reference PDFs and rendered manual pages are not included in these assets.
Actual LCD contrast, font/modifier behavior, cursor/blink/repeat cadence and
MENU/Fugue transitions remain **HARDWARE TEST REQUIRED**.
