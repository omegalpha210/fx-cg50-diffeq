# Host UI review frames

These 56 application views and overview sheets are generated by the production
UI and the attributed gint host drawing/key adapter. They are not calculator or
CPU-emulator screenshots. Current source: the development milestone 0de88c7.

After `./tools/test.sh`, run `python3 tools/capture_ui.py` with Pillow installed.
`polish-overview.png` focuses on contextual hints, logical EDIT, magenta Graph
PREV, pale swatches and mode-aware SF. `ux-field-overview.png` includes earlier
TRACE, field and simplified OUTPUT/IC/Table regression views.

The README's focused, consistent example is generated separately by
`tools/capture_readme.py`; see [image provenance](../images/README.md).
No manual or extracted page is included. LCD contrast, key/timer behavior,
MENU/Fugue and native storage remain HARDWARE TEST REQUIRED.
